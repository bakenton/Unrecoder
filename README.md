# Unrecoder

Игра про шифровальщика в офисе разведки: он принимает сообщения агентов, расшифровывает их по кодовой таблице и докладывает командованию. Шифр всегда решаем — но от тебя зависит, какое прочтение подходит ситуации прямо сейчас. (Питч и план описывают прежний сеттинг с горной экспедицией.)

- Питч: `docs/Unrecoder_Pitch_EN.pdf`
- План разработки: [docs/PLAN.md](docs/PLAN.md) (устарел: прежний сеттинг)
- Что сделано и почему: [docs/DESIGN.md](docs/DESIGN.md)
- Идеи и открытые вопросы: [docs/IDEAS.md](docs/IDEAS.md)
- С чего начать новую сессию: [docs/HANDOFF.md](docs/HANDOFF.md)
- Журнал сессий: [docs/chat-log.md](docs/chat-log.md)

Статус: играбельный HTML-прототип (5 смен по 5 сообщений, обучение, сохранения, 7 тестовых уровней с усложнениями шифра). Порт в Unity позже.

## Запуск прототипа

**Самый простой способ:** открыть двойным кликом `prototype/unrecoder-standalone.html` — один файл, сервер не нужен.
Он собирается командой `cd prototype && node build-standalone.mjs` (пересобирать после правок в `src/`, `style.css`, `index.html` или `content/`).

**Режим разработки:** двойной клик по `run-prototype.bat` (запускает сервер и открывает браузер), либо из корня репозитория:

```bash
python -m http.server 5173
```

и открыть http://localhost:5173/prototype/index.html. Сервер обязательно запускать из корня репозитория — контент лежит в `content/`. Файл `prototype/index.html` напрямую двойным кликом не откроется (браузер блокирует модули по `file://`) — для этого есть standalone-версия.

Тесты логики: `cd prototype && node --test src/core/` (нужен Node 20+).
