# Unrecoder: с чего начать новую сессию

Состояние на 20.10.2026. Коротко и по делу; подробности в [DESIGN.md](DESIGN.md), идеи в [IDEAS.md](IDEAS.md), история разговоров в [chat-log.md](chat-log.md).

## Где что лежит

| Что | Где |
|---|---|
| Играть без сервера | `prototype/unrecoder-standalone.html` (двойной клик) |
| Режим разработки | `run-prototype.bat` или `python -m http.server 5173` из корня, затем `http://localhost:5173/prototype/index.html` |
| Пересобрать standalone | `cd prototype && node build-standalone.mjs` (после любых правок в `src/`, `style.css`, `index.html`, `content/`) |
| Тесты логики | `cd prototype && node --test src/core/` (сейчас 44, все проходят) |
| Логика без интерфейса | `prototype/src/core/engine.js` (порт в Unity позже) |
| Интерфейс | `prototype/src/main.js`, `index.html`, `style.css` |
| Контент (таблица, агенты, 25 сообщений) | `content/campaign/act1.json`, собирается `content/tools/make_act1.mjs` |

Хранилища браузера у standalone-файла и у страницы с сервера разные; прогресс переносится через SAVE GAME / LOAD GAME.

## Что есть в прототипе

- **Основная игра:** 5 смен по 5 сообщений и ответ агентам. Вводная карточка, тур по папке, мигающая первая группа, советник Пайк (затемнение, подсветка панели, карточка рядом).
- **Цена ошибки:** 3 неверных клика, и сообщение потеряно (−1 Интуиция). Действует со 2-й смены; первая смена без лимита.
- **Сохранения:** автосейв после каждого решённого сообщения (возобновление с последнего), SAVE GAME / LOAD GAME / NEW GAME. Лог игры отдельно кнопкой «Save as JSON».
- **Тестовые уровни** (полка TEST LEVELS, только для плейтестов, в основной игре усложнений нет): 1 новая стартовая буква, 2 перемешанная таблица, 3 сдвиг Цезаря (колесо), 4 зеркало (колесо + FLIP), 5 смазанные буквы, 6 «Cipher day», 7 «Everything». Колесо и карандаш ✎ описаны в DESIGN.md.

## Принятые решения (не пересматривать без причины)

- Усложнять **имеющийся шифр**, а не писать новые. Загадки «шифр + текст + отчёт по агенту» отложены.
- Хорошо играются усложнения-**решения** (смазанные и потерянные буквы, поиск стартовой буквы, перемешанная таблица), плохо усложнения-**процедуры** (читать правило и сравнивать символы). Для сдвига и зеркала поэтому колесо и карандаш.
- Для основной игры потолок: **два-три усложнения одновременно**. «Everything» (4) уже на грани.
- «Ось» и «поменянные оси» остались в движке и тестах, но из уровней убраны как слишком «читательные».
- Смены остаются для основной игры; усложнения в них ещё не включены.

2. **Решить, какие усложнения идут в какие смены** основной игры (поле `twists` в сообщениях смены уже поддерживается движком). Начинать с одного на смену.

4. **Ослабить или убрать лимит ошибок в сменах,** если тестеры будут жаловаться: условие в `errorLimit` (engine.js).
5. Обновить `docs/PLAN.md` и питч (описывают прежний сеттинг), выбрать эпоху и страну, сюжет пяти смен.

## Как мы работаем (чтобы не переспрашивать)

- Автор пишет по-русски. Термины: **«матрица»** = сетка букв сигнала, **«таблица»** = кодовая таблица 10×10.
- Автор тестирует прототип и присылает скриншоты с отзывом; в ответ ожидает либо варианты («нужны варианты» значит ничего не реализовывать), либо реализацию.
- Коммиты идут прямо в `main` и только по просьбе («закомить»); пушит автор через GitHub Desktop.
- Правки файлов осторожно с переводами строк: часть файлов в репозитории CRLF, часть LF. Скрипт правки не должен менять тип переводов строк (однажды это сломало сборку standalone).
- В ответах по-русски избегать родовых форм о себе (пол не задан).
